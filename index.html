🎵 AI 精選睡前舒壓影音

技術流程：YouTube API 搜尋 ➔ 字幕音訊下載 ➔ Whisper 轉文字 ➔ OpenAI GPT 內容過濾與舒壓評分（排除刺激/新聞類）。

點擊「開始 AI 掃描」獲取經 Whisper + GPT 深度分析的前 10 名催眠影音
// server.js 核心邏輯參考 const { OpenAI } = require("openai"); const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY }); app.get("/api/relax-videos", async (req, res) => { try { // 1. 呼叫 YouTube Data API 搜尋特定關鍵字 const keywords = ["輕音樂", "睡眠音樂", "白噪音", "雨聲", "鋼琴音樂", "冥想音樂"]; const searchKeyword = keywords[Math.floor(Math.random() * keywords.length)]; const ytResponse = await fetch(`https://www.googleapis.com/youtube/v3/search?part=snippet&q=${encodeURIComponent(searchKeyword)}&type=video&maxResults=15&key=${process.env.YOUTUBE_API_KEY}`); const ytData = await ytResponse.json(); let recommendedVideos = []; for (let video of ytData.items) { const videoId = video.id.videoId; const title = video.snippet.title; const description = video.snippet.description; // 2. 下載字幕/音訊 並透過 Whisper 轉文字 // 提示：實務上可以先抓取 YouTube 內建的 Tracks (字幕)，若無字幕，則利用 ytdl-core 下載音訊片段， // 丟給 OpenAI Whisper API： /* const transcription = await openai.audio.transcriptions.create({ file: fs.createReadStream(`audio_${videoId}.mp3`), model: "whisper-1", }); */ const mockText = "這是一段平穩、緩慢的下雨聲與輕柔的鋼琴旋律，沒有任何說話聲..."; // 3. 呼叫 GPT 進行安全過濾與舒壓評分 const aiPrompt = ` 你是一個專業的睡眠與物理治療 AI 助手。請分析以下 YouTube 影片內容（含標題、描述與字幕文本）： 標題：${title} 描述：${description} 轉譯文字：${mockText} 請依據以下標準審查： 1. 嚴格排除遊戲、新聞、搞笑、驚悚或刺激類影片。如果是這類影片，請直接判定不適合。 2. 根據舒壓程度給予 1~10 分的評分。 3. 給出 50 字以內的推薦或拒絕理由。 請嚴格以 JSON 格式輸出： { "suitable": true 或 false, "score": 數字(1-10), "reason": "推薦理由" } `; const completion = await openai.chat.completions.create({ model: "gpt-4o", // 或是使用 2026 年最新穩定的模型 messages: [{ role: "user", content: aiPrompt }], response_format: { type: "json_object" } }); const aiResult = JSON.parse(completion.choices[0].message.content); // 4. 篩選並放入推薦清單 if (aiResult.suitable) { recommendedVideos.push({ id: videoId, title, channel: video.snippet.channelTitle, score: aiResult.score, reason: aiResult.reason }); } } // 5. 排序取前 10 名回傳給前端 recommendedVideos.sort((a, b) => b.score - a.score); res.json(recommendedVideos.slice(0, 10)); } catch (error) { res.status(500).json({ error: error.message }); } });
